## 👋 About Me

I build the systems that run behind the scenes — **automation pipelines, CRM workflows, and integrations** that turn manual busywork into something that just runs.

- 🤖 **AI Automation** — GoHighLevel builds, CRM pipelines, and LLM-driven workflows (Claude Code, MCP)
- 🧩 **Full Stack** — end-to-end web & mobile on the **MERN stack** and **Laravel**, clean MVC, REST APIs built to scale
- 🔌 **Integrations** — live third-party wiring: Stripe, ElevenLabs, WhatsApp Business, Meta, GHL
- 🛡️ **Application Security** — auth/JWT, OWASP-aware API design, secrets management, secure payments
- 🎓 **BS Computer Science — Cum Laude**, Naga College Foundation (2022 – 2026)

> I care about systems that are reliable under real usage, not just demos — clean data flow, solid API contracts, and QA discipline baked in from the start.
